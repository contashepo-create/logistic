## ✨ الميزات (حسب وثيقة المواصفات)

### 🌟 قواعد عامة على مستوى النظام
- **التصدير والطباعة:** كل جدول/تقرير/كشف حساب مزوّد بأزرار **📊 Excel** و **📄 PDF** و **🖨️ طباعة** بتنسيق احترافي (ترويسة الشركة + جدول منسق + تذييل).
- **إدارة العمليات (CRUD):** بجانب كل حركة أزرار (عرض 👁️) (تعديل ✏️) (حذف 🗑️) + أزرار خاصة (كشف حساب 📄، طباعة فاتورة 🖨️، لقطة إغلاق 🖼️).
- **المعالجة التلقائية:** الأرصدة (العميل/الخزينة/البنك/ربح الرحلة/الأرباح العامة) تُحسب لحظياً من الحركات، فأي تعديل أو حذف يُعيد الاحتساب بأثر رجعي فوراً.
- **قاعدة السنوات المالية:** لا يمكن إضافة/تعديل/حذف أي حركة خارج نطاق سنة مالية **مفتوحة**.

### 📂 البيانات الأساسية
- **العملاء:** كود تلقائي، هاتف (نص يحفظ الأصفار)، رصيد افتتاحي، رصيد حالي تلقائي، ملاحظات، وزر **كشف حساب** بفلاتر تاريخ.
- **الموظفون والسائقون:** كود تلقائي، جنسية، نوع (سائق/إداري)، ملاحظات.
- **السيارات:** كود تلقائي، رقم اللوحة، النوع، سائق افتراضي.
- **الموردون:** كود تلقائي، هاتف، رقم ضريبي وسجل تجاري، نوع الكيان والحالة الضريبية، العنوان الوطني، **أجل السداد بالأيام**، رصيد افتتاحي، ورصيد مستحق يُحسب لحظياً من فواتير المشتريات ناقص سندات السداد.
- **السنوات المالية:** من/إلى تاريخ، حالة (مفتوحة/مغلقة)، إغلاق يولّد **لقطة إغلاق Snapshot** (أرصدة العملاء والخزائن والبنوك + أرباح السنة).

### 🏦 الخزائن والبنوك
- **الخزائن:** رصيد افتتاحي/حالي تلقائي + كشف حساب بكل حركات القبض والدفع.
- **البنوك:** رقم حساب + IBAN + رصيد تلقائي + كشف حساب.

### 🔄 العمليات اليومية
- **فواتير النقل:** رأس الفاتورة (عميل/تاريخ/مرفقات/ملاحظات/**نسبة الضريبة**) + نقلات (سيارة، سائق، من، إلى، **عدد النقلات × سعر الوحدة**، **أرقام الحاويات**) + مصروفات لكل نقلة (**كمية × قيمة الوحدة** + **مصدر التمويل**) + إجماليات (قيمة النقلات، مصروف يتحمّله العميل، التكلفة المباشرة، الربح المتوقع، ضريبة القيمة المضافة، الإجمالي على العميل).
- **مصادر تمويل مصروف النقلة** — وهي جوهر المطابقة مع نموذج الويب:
  - *نقدي* → يُنشئ **سند دفع تلقائياً** ويربطه بالمصروف ويُخصم من الخزينة/البنك فوراً (مع منع الرصيد السالب).
  - *على السائق* → يُحمّل على السائق ويظهر في كشف حسابه.
  - *على المورد (آجل)* → التزام مؤجّل لا يمسّ النقد.
  - *على العميل* → ليس تكلفة علينا؛ يُضاف لوعاء الضريبة ولمطالبة العميل (`billable_total`).
- **الضريبة:** `قيمة الضريبة = تقريب(الوعاء × النسبة / 100)`، والوعاء = قيمة النقلات + مصروفات العميل. `الإجمالي على العميل = الوعاء + الضريبة`.
- **الفاتورة غير قابلة للتعديل بعد الإصدار** — التصحيح بإشعار دائن أو مدين فقط (مطابقةً لمتطلبات الفوترة الضريبية).
- **المبلغ كتابةً (التفقيط):** يظهر في الفاتورة المطبوعة بالعربية الكاملة («مائة وخمسة وعشرون ريال فقط لا غير»)، مع جانب الرصيد (عليه/له/مسدَّد) في قائمتي العملاء والموردين.
- **🖨️ طباعة الفاتورة:** فاتورة ضريبية (B2B) أو مبسّطة (B2C) حسب حالة العميل، تتضمن **رمز QR وفق مواصفة ZATCA** (TLV → Base64: اسم البائع، الرقم الضريبي، الطابع الزمني، الإجمالي شامل الضريبة، قيمة الضريبة)، وتُخفي المصروفات والربح تماماً.
- **فواتير المشتريات:** رأس (مورّد/تاريخ/نوع آجلة أو نقدية/بند المصروف/مرجع/الضريبة شاملة أم لا) + بنود (اسم/وحدة/كمية/سعر/نسبة ضريبة). النقدية تُنشئ سند دفع تلقائياً، والآجلة تُحمّل على رصيد المورّد. المصروف يُثبَّت في الأرباح والخسائر عند تاريخ الفاتورة في الحالتين.
- **إشعارات مدين/دائن:** الإشعار الدائن يُصدر **بمرتجع نقلات محددة** (النظام يقرأ أسعار النقلات ونسبة ضريبة الفاتورة ولا يثق بأي مبلغ مُرسل)، ويرفض إرجاع نقلة مرتجعة سابقاً. الإشعار المدين يضيف مطالبة. السبب إلزامي، ويجب أن يكون عميل الإشعار هو عميل الفاتورة وتاريخه ≥ تاريخها.
- **سندات القبض:** إيداع في خزينة/بنك؛ تحصيل من عميل (يقلل مديونيته) أو إيرادات أخرى (خردة/متنوع → الأرباح العامة).
- **سندات الدفع:** صرف من خزينة/بنك بسبعة توجيهات (`المبلغ = الكمية × قيمة الوحدة`):
  - *مصروف يخص رحلة* → يُخصم من ربح النقلة بأثر رجعي.
  - *سلفة موظف/سائق* → تبقى مستحقة حتى خصمها من الرواتب.
  - *مصروف لسيارة (صيانة/كاوتش)* → يظهر في تقرير أداء السيارة.
  - *سداد مورّد* → يرتبط بفاتورة مشتريات ويقلل الرصيد المستحق له.
  - *مشتريات نقدية* → ترتبط ببند مصروف في الأرباح والخسائر.
  - *سحب مالك* → يُفصل عن المصروفات التشغيلية.
  - *مصروف عام (إيجار/كهرباء)* → يُخصم من الربح العام.

### 💰 الرواتب
- **بنود الخصم:** تسجيل خصومات على الموظف (مخالفات/تلفيات/عهدة) بحالة (قائمة/مسددة)، تُسوّى من الرواتب.
- إصدار راتب: الموظف، الشهر/السنة، جهة الصرف، الأساسي، إضافات + بيان، **سجل السلفيات غير المسددة وسجل الخصومات يظهران تلقائياً** مع تسوية كاملة أو جزئية لكل بند، خصومات أخرى، و`الصافي = الأساسي + الإضافات − خصم السلف − خصم البنود − الخصومات الأخرى`.
- قواعد الحماية: يُرفض الصافي السالب، ويُرفض تجاوز المتبقي من أي سلفة أو بند، ويجب أن يطابق مجموع التسويات الإجمالي المعلن (±0.01). السلفة أو البند الذي عليه تسوية **لا يُعدَّل ولا يُحذف**.

### 📊 التقارير الذكية (كلها بفلاتر تاريخ + Excel/PDF/طباعة)
1. **أرباح الفواتير والرحلات:** الإيراد − المصروف المباشر وقت الفاتورة − المصاريف اللاحقة من سندات الدفع = الربح الفعلي لكل نقلة.
2. **كشف حساب عميل:** الافتتاحي + الفواتير + مصروفات العميل + أثر الإشعارات − سندات القبض = الرصيد الحالي.
3. **كشف حساب مورّد:** فواتير المشتريات (صافي/ضريبة/إجمالي) − سندات السداد = المستحق للمورّد.
4. **كشف حساب موظف/سائق:** الرواتب تفصيلياً + السلف والخصومات وتواريخ تسويتها + بدلات التريب من الفواتير.
5. **أعمار الديون:** توزيع المستحقات على شرائح (حتى 30 / 31–60 / 61–90 / أكثر من 90 يوماً) بأسلوب **FIFO** — السداد يُخصم من أقدم فاتورة أولاً. تبويب للموردين (ما علينا) وتبويب للعملاء (ما لنا).
6. **أداء السيارات:** إيراداتها − مصروفات رحلاتها − صيانتها = صافي الربحية.
7. **الأرباح والخسائر (P&L):** إيرادات النقل + إيرادات أخرى + صافي الإشعارات − (التكلفة المباشرة + مدفوعات النقلات + الرواتب + السلف + الصيانة + العامة + **المشتريات مفصّلة حسب البند** + سحب المالك)، مع سطر مستقل **لضريبة القيمة المضافة المحصّلة**.

### ⚙️ الإعدادات
- ترويسة الطباعة + **الحزمة الضريبية للمنشأة** (الاسم، الرقم الضريبي، السجل التجاري، العنوان الوطني) ونسبة الضريبة الافتراضية.
- **مؤشر جاهزية ZATCA حي:** يُظهر الحقول الناقصة التي تمنع إصدار فاتورة ضريبية كاملة.

## 🚀 التشغيل

### المتطلبات
- Python 3.10+ (مُختبر على 3.11)

### خطوات التشغيل
```bash
cd logistic
pip install -r requirements.txt
python main.py
```

عند أول تشغيل سيقترح البرنامج إنشاء السنة المالية الحالية تلقائياً. بعدها:
1. أدخل العملاء/الموظفين/السيارات/الخزائن/البنوك من **البيانات الأساسية** و**الخزائن والبنوك**.

## 🧠 قرارات محاسبية مضمّنة
- إجمالي فاتورة العميل = أسعار النقلات + المصروفات التي يتحمّلها العميل،
  والضريبة تُحسب على هذا المجموع (مطابق لـ `totalsFrom` في نسخة الويب).
  أمّا المصروفات بتمويل نقدي/السائق/المورّد فتكلفة مباشرة تُخصم من الربح
  ولا تدخل وعاء الضريبة.
- رصيد الخزينة/البنك = الافتتاحي + المقبوضات − المدفوعات − الرواتب المنصرفة.
- حذف فاتورة مرتبطة بسندات دفع (مصروف رحلة) **ممنوع** — تُحذف السندات أولاً.
- سلفة خُصمت في رواتب لا تُعدَّل ولا تُحذف إلا بعد حذف الرواتب المرتبطة (حفاظاً على الدقة).
- حذف راتب يُرجع السلف المخصومة إلى "غير مسددة" تلقائياً.

## 📝 ملاحظات
- الفاتورة الرسمية للعميل لا تخضع لـ ZATCA (عبارة قابلة للتعديل من الإعدادات).
- الأرقام العربية (٠-٩) مقبولة في كل حقول المبالغ تلقائياً.
- التطبيق يعمل دون أي اتصال بالإنترنت؛ بياناتك تبقى على جهازك.
